# Contributing

Bug reports and focused pull requests are welcome.

When reporting a power-management issue, include:

- Mac model and processor family;
- macOS version;
- whether power is connected through MagSafe, USB-C, or a display/dock;
- output from `pmset -g` with any personal information removed;
- exact steps to reproduce.

Do not test lid-closed behavior with the MacBook inside a bag or an unventilated space.
